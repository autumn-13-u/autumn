# Autumn

Autumn is a long-term personal AI project. The aim is to learn solid software engineering, Python, machine learning, and AI by building the project gradually and understanding every part of it.

## Current focus

**Step 1 — Software engineering foundation**

The project is intentionally restarting from scratch. Product features, memory, authentication, and AI capabilities will be introduced only after their foundations have been learned and built.

## Learning path

1. Software engineering foundation
2. Backend
3. Data layer
4. Backend ↔ frontend communication / API
5. Frontend
6. Authentication
7. Memory
8. AI capabilities

## Project structure

```text
autumn/
├── backend/      # Future backend and API
├── frontend/     # Future user interface
├── data/         # Future local data layer
├── tests/        # Tests added alongside each learned feature
├── lesson_01.py  # Current learning exercise — written by the project owner
└── README.md
```

The frontend will communicate with the backend; it will not work directly with the project data files.
